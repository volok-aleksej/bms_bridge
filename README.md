This project makes it possible to connect an inverter that supports the Pylontech protocol to a battery using a JKong BMS BD version that does not have built-in CAN port support.

The application is installed on an inexpensive nettop, connects to the inverter via an RS485-to-UART converter, and communicates with the battery over Bluetooth.

The program keeps a history of the data received from the battery and includes a built-in HTTP server that allows real-time monitoring of all battery parameters and historical graphs directly through a web browser.
